## Навыки и технологии

В ходе работы над проектом были освоены и продемонстрированы следующие навыки:

### Управление версиями

- Создание и настройка репозитория на GitHub
- Клонирование репозитория на локальный компьютер
- Использование основных команд Git:
  - `clone`
  - `add`
  - `commit`
  - `push`
- Работа с ветками и синхронизация с удалённым репозиторием
- Настройка GitHub Pages для хостинга проекта

### Веб-разработка (HTML)

- Создание базовой структуры HTML-документа
- Использование тегов заголовков (`h1–h6`)
- Работа со ссылками (`<a>`) и навигацией между страницами
- Добавление изображений (`<img>`) на веб-страницы
- Создание:
  - упорядоченных списков (`<ol>`)
  - неупорядоченных списков (`<ul>`)
- Использование абзацев (`<p>`) для текстового контента
- Понимание относительных путей (`../`, `recipes/`)
- Организация файловой структуры проекта
